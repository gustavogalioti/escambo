# ESCAMBO 🔄

> *Poste o que você tem. Receba propostas do que nunca imaginou querer.*

Plataforma de trocas entre pessoas — sem dinheiro, sem complicação. O usuário anuncia um item e recebe propostas de outros usuários interessados em trocar.

## Como funciona

1. **Anuncie** o que você tem com fotos e descrição
2. **Receba propostas** de quem quer trocar com você
3. **Feche o negócio** diretamente com o interessado

## Rodando localmente

```bash
npm install
npm start
```

Acesse em `http://localhost:3000`

## Deploy (Vercel)

```bash
npm run build
```

Ou conecte o repositório diretamente no [Vercel](https://vercel.com) — deploy automático a cada push.

## Stack

- React 18
- CSS-in-JS (CSS variables nativas)
- Google Fonts (Playfair Display + DM Sans)
- Dados mockados (pronto para integração com backend)
